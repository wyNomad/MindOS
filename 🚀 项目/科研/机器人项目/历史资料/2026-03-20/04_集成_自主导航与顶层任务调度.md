# 04 集成：自主导航与顶层任务调度

在打通了感知与执行的链路后，项目的目标开始转向真正的自主性。这涉及路径规划，以及一套灵活的顶层逻辑来统筹管理各项任务。在这个阶段，重点聚焦于多模态融合下的任务决策系统。

## 1. 导航适配：Nav2 与 3D 重定位的深度协同

系统采用 ROS 2 的导航框架 **Nav2**。针对全向底盘特性，进行了针对性配置，使机器人可以在不改变航向的情况下执行横向平移，从而提升其在狭窄环境中的通行效率。

为了应对位置突变或定位丢失的异常情况，利用 RTAB-Map 的 3D 视觉重定位能力作为兜底。当系统检测到当前图像与地图库中的场景高度匹配时，会触发全局重定位以修正位姿。这实现了 3D 视觉定位与 2D 经典导航的互补，提升了系统鲁棒性。

## 2. 逻辑调度：层级状态机下的多任务管理

在顶层应用上，使用 Python 编写了一套层级状态机，配合 `Nav2 Simple Commander` 接口，实现任务的柔性调度。

- **融合跟随模式（Fusion Follower）**：采用视觉定角度、雷达定距离的混合策略。视觉算法提取目标在图像中的偏航角，激光雷达随即在对应探测扇区内寻找最近的动态团块以获取精确距离。这种多模态融合方案显著提升了跟随鲁棒性。
- **任务自愈机制**：当视觉丢失目标时，状态机立即接管，控制小车切换回巡检路径。一旦重新捕获特征，系统又能无缝切回锁定跟随状态。

## 3. 工程优化：基于像素几何的精准停车

在执行特定巡检任务时，引入了一个基于像素几何的触发逻辑。由于摄像头侧向安装，随着机器人前进，目标在视野中会产生位移。算法中设定一条中心触发线：当目标的像素质心跨越图像垂直中轴时，判定机器人已抵达目标正侧方。

这种将 3D 定位问题简化为 2D 像素坐标系交汇的方案，有效避开了复杂深度解算带来的累积误差，提升了触发精度与实时性。

## 4. 系统级调优：算力瓶颈与时间戳对齐

为了确保整个系统的实时性，在香橙派 5 Plus 上实施了严格的资源管理。

- **CPU 亲和性（CPU Affinity）**：将关键的 EKF 节点与串口解析线程绑定到高性能大核上。
- **降频与同步**：对非核心传感器流进行主动降频，并严格校准全局时间戳，防止因算力波动导致控制指令延迟。

## 本章结论

从底层 PWM 控制到顶层任务调度，这套系统实现了技术链路的完整闭环。系统真正的自主性，不只是体现在导航成功率上，更体现在模式切换、自愈能力与工程稳定性上。
