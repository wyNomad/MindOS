# 📌 ros2 自主移动机器人当前状态与计划

## 当前系统状态

- 键盘节点可驱动底盘运动
- 相机话题、雷达话题正常产出
- 底盘反馈轮式里程计可用
- IMU 数据可用
- RTAB-Map 的 `icp_odometry` 可用
- EKF 已融合出标准里程计 `/odometry/filtered`
- RTAB-Map 建图可用
- Nav2 已完成对接，A→B 导航有时成功

## 机器人关键信息

- 三轮全向轮（omni wheel）结构，非差速驱动
- 实际半径约 `0.11 ~ 0.12m`
- costmap 中 `robot_radius` 当前设为 `0.20m`
- IMU 安装在 `base_link` 前方约 2cm

## 关键频率信息

- `/scan`：约 12 Hz
- RGB + Depth：约 30 Hz，SLAM 场景中降频至 15 Hz 输入 `rgbd_sync`
- IMU：约 50 Hz
- `/wheel/odom`：50 Hz

## TF 结构

```text
map → odom → base_link → laser_link → laser
                       → camera_link
                       → imu_link
                       → front/left/right_wheel_link
```

说明：
- `map → odom`：导航阶段由 AMCL 发布
- `odom → base_link`：由 EKF 发布

## 启动模式

### 建图阶段

- 运行 `slam_launch.py`
- 使用 RTAB-Map 建图
- 启用 `icp_odometry`
- 使用 EKF 融合
- 必要时启用视觉里程计相关配置

### 导航阶段

- 运行导航启动文件
- 使用 AMCL + Nav2
- 当前导航阶段不启用视觉里程计
- `odom` 到 `/odometry/filtered` 的重映射已处理

## 常用命令

### 编译

```bash
cd /home/orangepi/ros2
colcon build --packages-select chassis_driver my_robot_slam my_robot_navi --symlink-install
source install/setup.bash
```

### 常见运行

```bash
ros2 run chassis_driver serial_bridge
ros2 run imu_odometry imu_node
ros2 launch my_robot_slam slam_launch.py
ros2 launch my_robot_navi bringup_launch.py
```

### 调试

```bash
ros2 topic list
ros2 topic echo /topic
ros2 node list
ros2 doctor
```
