# 03 认知：多模态感知与 EKF 状态估计

如果说底层通信是机器人的基础链路，那么感知系统则是其理解环境的核心层。本章探讨如何让机器人具备获取外界信息并进行空间认知的能力，这个过程涉及多种传感器的选型、标定以及数据融合的权衡。

## 1. 异构传感器的时空对齐

为了获得最稳健的位姿，构建了一个涵盖四源传感器的感知网络，这是机器人建立环境表征的基础。

- **轮式里程计（`/wheel/odom`）**：提供高频的基础相对运动趋势，虽然存在漂移，但在短时间内具有极高的线性精度。
- **IMU 惯性单元（`/imu/odom`）**：采用 IMU900 模块。其提供的四元数在融合中被赋予极高的信任权重，专门用于压制偏航角（Yaw）的漂移，为系统提供绝对的朝向参考。
- **雷达里程计（`/lidar/odom`）**：基于 LS Lidar N10P。将其点云推入 RTAB-Map 的 `icp_odometry` 节点，通过帧间匹配（ICP 算法）重定义协方差，作为独立的运动估计源。
- **视觉里程计（`/vision/odom`）**：基于 Astra Pro 深度相机。考虑到 USB 带宽与处理器算力负载，将分辨率控制在 `320x240`，并选择性关闭红外流，仅保留彩图与深度图。数据接入 `rgbd_odometry` 后，为系统提供关键的平移纠偏能力。

## 2. EKF 状态估计：多源数据融合

在物理世界中，单一传感器均存在局限性。为了获得稳健位姿，引入了 `robot_localization` 中的 EKF（扩展卡尔曼滤波）节点，并对不同传感器设置了不同的信任权重。

- **线速度（vx、vy）**：由轮速计主导。在 EKF 中，其协方差设为 `1e-5`。视觉里程计作为冗余参考，协方差约为 `5e-4`，用于辅助修正轮式滑移。
- **角速度（yaw_rate）**：由 IMU 绝对主导。IMU900 的响应迅速，协方差约为 `1e-4`，能瞬时捕获转向动作。

这种多源冗余配置，为机器人提供了低噪声、低漂移的位姿估计基准。

## 3. 空间认知：RTAB-Map 的图优化 SLAM

在建图策略上，选择了 RTAB-Map 进行多模态融合建图，这标志着机器人从 2D 栅格表征跃迁到了具备闭环检测能力的位姿图优化阶段。

- **多模态协同**：指定 2D 栅格地图由激光雷达生成，确保用于路径规划的边缘清晰；同时利用视觉特征的词袋模型（BoW）进行闭环检测。当机器人识别到历史场景时，会触发全局位姿图优化，从而消除累积运动误差。
- **数据精简**：通过生成的 `map.db` 文件，利用 `rtabmap-viewer` 做点云匹配优化和冗余数据剔除，确保地图具备工程实用性。

## 本章结论

通过 URDF 标定的 TF 坐标树，四源数据在 EKF 中汇流，输出的 `/odom/filter` 为后续自主导航提供了可靠的高精度底座。机器人不仅具备了稳定的运动链路，还拥有了具备空间逻辑的感知闭环。
