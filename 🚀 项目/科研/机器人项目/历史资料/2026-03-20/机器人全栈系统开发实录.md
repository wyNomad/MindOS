# 机器人全栈系统开发实录：基于 ROS 2 的分层具身智能集成

本项目是一份基于 **ROS 2 humble** 的分层具身智能（Hierarchical Embodied AI）系统集成实战笔记。

这套记录旨在沉淀一个机器人系统如何从基础环境搭建，逐步演化出感知、定位、导航和任务调度能力，并最终形成具备工程鲁棒性的系统链路。

## 🏗️ 系统架构与技术底座

- **多层级控制架构**：决策层（PC / VM） + 算力平台（Orange Pi 5 Plus） + 执行层（STM32）。
- **传感器集成**：Astra Pro（RGB-D） + LS Lidar N10P + IMU900。
- **状态估计方案**：基于 EKF 的四源异构传感器融合（轮式 + IMU + 雷达 ICP + 视觉 RGBD）。
- **逻辑调度**：基于 Python 的层级状态机（State Machine）与 Nav2 Simple Commander。

## 📌 补充视角

这组章节之外，项目还包含以下关键工程认识：

- 机器人高层智能的成立，前提是底层控制与通信链路足够稳定。
- 传感器融合不是简单叠加，而是不同误差模型之间的权重分配。
- 在真实物理环境中，性能优化、时间戳对齐、资源调度与算法本身同样重要。
- 顶层任务系统的价值不只在于“能跑”，更在于在目标丢失、定位漂移、模式切换时保持自愈能力。

## 核心工程理念

> 机器人工程的实践证明，地基的稳固（底层控制与通信）是实现高级智能（导航与调度）的先决条件。
