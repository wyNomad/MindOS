# ⚙️ 偏好

## 工作习惯

- 习惯将大目标拆解为小目标，按步骤逐步推进与实践。
- 能较清晰地向 AI 描述当前情况与需求。
- 遇到不懂的内容会及时追问，而不是在模糊理解下继续推进。

## 工具偏好

- 香橙派 5 Plus 上的 Ubuntu 22.04 是主要开发环境。
- 常用 VS Code 配合插件查看、修改和润色工程代码。
- 会在笔记本电脑上通过 MobaXterm 和 Trae 远程连接香橙派进行控制、开发与代码编写。
- 终端中部署了 Claude Code 和 Codex 作为主要 AI 开发助手。
- 倾向让 AI 直接在终端中读取代码、给出建议，并在确认方向后自主修改。
- 在 Claude Code 中常结合 Serena 插件理解特定工程代码并获取建议与看法。
- 模块化代码层面的实现与修改，更倾向交给 Codex 作为主力。

## 沟通偏好

- 擅长先说明背景、现状与目标，再进入具体问题。
- 偏好围绕当前任务直接沟通，发现理解偏差时及时澄清。
- 更适合基于明确上下文进行多轮迭代，而不是一次性给出过于抽象的结论。

## 写作偏好

- 暂未固化单一写作风格，优先追求围绕任务目标清晰表达。

## AI 使用偏好

- 希望 AI 先读取代码与上下文，再给出建议，而不是脱离实际泛泛而谈。
- 对工程理解、方案分析与代码修改都接受，但希望过程围绕真实项目结构展开。
- 适合让不同 Agent 分工：Claude Code 偏向结合 Serena 做工程理解与建议，Codex 偏向模块化实现与改动落地。
- 在远程开发场景下，也会配合使用 Trae 及其内置 AI 进行辅助。
