# 🧠 MindOS 使用说明

## 目标

- 用最直接的方式说明 MindOS 各分区分别记录什么。
- 帮助自己快速判断“这条信息该放哪里”。
- 明确平时查看进度、动态、待办时应该优先看哪些位置。

## 核心理解

可以把 MindOS 理解为六个问题：

- `👤 画像/`：我是谁
- `🚀 项目/`：我在做什么
- `🔄 流程/`：我怎么做
- `📝 笔记/`：我今天先记下来什么
- `📚 资源/`：我参考了什么
- `🔗 关系/`：我和谁有关

## 分区说明

### 👤 画像

适合记录：
- 长期稳定的个人背景
- 工具偏好、沟通偏好、AI 协作偏好
- 当前阶段重点、长期方向、年度目标

不适合记录：
- 临时笔记
- 当天排错过程
- 某个具体项目的阶段细节

当前主要文件：
- `👤 身份.md`
- `⚙️ 偏好.md`
- `🎯 聚焦.md`

### 📝 笔记

适合记录：
- 临时速记
- 当天工作记录
- 排错过程
- 尚未整理的想法
- 会议纪要
- 等待别人反馈的事项

子目录建议：
- `收件箱/`：先记下来，之后再整理
- `待反馈/`：等他人回复、等外部依赖
- `会议/`：会议纪要、决策、行动项
- `想法/`：灵感、选题、实验点子

不适合记录：
- 已经稳定成型的长期知识
- 明确属于项目档案或 SOP 的内容

### 🚀 项目

适合记录：
- 当前正在推进的项目档案
- 项目背景、目标、范围
- 当前进度、关键决策、里程碑
- 下次继续时需要先看的内容

不适合记录：
- 与具体项目无关的长期偏好
- 只是临时想到、尚未确定归属的碎片信息

### 🔄 流程

适合记录：
- 可复用的工作方法
- SOP
- 固定协作流程
- 学习路线
- 周计划模板
- 会话结束前的收尾沉淀规则

判断标准：
- 如果这件事以后还会重复做，优先考虑写到这里。

### 📚 资源

适合记录：
- 外部资料索引
- 工具清单
- 课程、论文、网站、博主、书单
- 结构化资源列表

不适合记录：
- 自己当天的心得
- 项目阶段进展

### 🔗 关系

适合记录：
- 同学、老师、朋友、合作对象的信息
- 与某人的合作背景
- 沟通注意点
- 人物索引与分类

不适合记录：
- 普通聊天原文
- 与人物无关的项目资料

## 放置判断法

每次记东西前，先问两句：

1. 这是临时的，还是长期的？
- 临时的、还没整理好的：先放 `📝 笔记/`
- 长期稳定的：看是否应归到 `👤 画像/`、`🚀 项目/`、`🔄 流程/`、`📚 资源/`、`🔗 关系/`

2. 这是内容，还是方法？
- 内容：放 `画像 / 笔记 / 项目 / 资源 / 关系`
- 方法：放 `流程`

## 平时去哪里看

### 看今天要做什么

优先看：
- `TODO.md`

### 看最近有什么变化

优先看：
- MindOS 首页的 `Recently Modified`

### 看已经完成了什么

优先看：
- `CHANGELOG.md`

### 看有哪些事卡在别人那里

优先看：
- `📝 笔记/待反馈/`

### 看当前项目做到哪里

优先看：
- `🚀 项目/` 下对应项目文档

### 看自己当前阶段重点

优先看：
- `👤 画像/🎯 聚焦.md`

## 日常使用建议

### 开始做事前

1. 看 `TODO.md`
2. 看当前项目文档或 `🎯 聚焦.md`
3. 明确今天要推进哪一个主题

### 做事过程中

1. 临时记录先放 `📝 笔记/收件箱/`
2. 如果是会议或讨论，放 `会议/`
3. 如果是等别人回复的事情，放 `待反馈/`

### 一天结束前

1. 用 3-5 分钟做一次轻量收尾
2. 记录：
   - 今天完成了什么
   - 当前进度
   - 关键决策
   - 踩坑/问题
   - 下次继续先做什么
3. 再判断是否需要把内容迁移到 `项目 / 流程 / 画像`

## 对 Agent 的使用方式

如果希望 Agent 稳定使用 MindOS 内容，提需求时尽量显式说：

- `按我 MindOS 里的内容来`
- `先读取我的 MindOS，再回答我`
- `把这次对话沉淀到 MindOS`
- `按我 MindOS 里的流程协助我`

## MindOS 与 Agent 记忆的边界

可以把当前这套协作结构理解成三层：

- `MindOS`：共享大脑。适合沉淀长期有效、跨对话要复用的内容。
- `Serena / 项目局部记录`：工程上下文层。适合记录代码结构、模块理解、阶段性技术结论。
- `Codex / Claude 的全局记忆`：各自私有的小便签。只适合保留少量稳定偏好，不适合承载项目主信息。

使用原则：

- 需要我、Claude 和你以后都能继续接上的内容，优先放 `MindOS`
- 与具体工程强相关的代码理解，可留在 `Serena` 或项目文档
- 不把项目进度、关键决策、长期学习规划只留在单次会话或某个 Agent 的私有记忆里

当前定位：

- `MindOS = 你 + Codex + Claude 的共享大脑`
- 同时也是开发记录库、学习记录库、项目交接库

## 验收标准

- 能快速判断一条信息该落到哪个分区。
- 平时知道去哪里看待办、动态、项目状态和阶段重点。
- 不再把所有信息混在一个目录里。
- 能把 MindOS 当作可持续维护的共享大脑来用。
